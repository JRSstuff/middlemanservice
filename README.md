# middlemanservice

A trusted middleman service platform developed for the **CS111 Startup Simulation Project** (CS111 Introduction to Computing • Section 1D • Team 4).

## 🚀 About the Project
A software platform designed to provide a secure and reliable escrow/middleman service for peer-to-peer student transactions, digital services, and student freelancing/micro-gigs.

## 🛠️ Setup & Contribution Guide
1. Pull latest changes before coding:
   ```bash
   git pull --rebase origin main
   ```
2. Check off your assigned tasks as you complete them:
   - Change `[ ]` to `[x]` under your name.
3. Commit and push:
   ```bash
   git add README.md
   git commit -m "docs: update task checklist for [Your Name]"
   git push origin main
   ```
4. All pushes are automatically announced in **`#📜・git-logs`** on Discord!
